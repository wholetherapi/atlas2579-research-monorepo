# Graphwave

Reference implementation for "GraphWave: Anomaly Detection on Irregular Sensor Graphs" (ICLR 2026).

This repository contains the complete reference implementation,
released under the MIT license.

## Layout

- `src/` - model and training code
- `data/` - data loaders
- `experiments/` - experiment configs
- `notebooks/` - analysis notebooks
- `results/` - reported metrics
- `tests/` - unit tests

## Usage

```
pip install -r requirements.txt
python -m src.model --help
```
